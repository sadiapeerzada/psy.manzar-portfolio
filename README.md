# Manazir — Interactive Portfolio

An interactive desktop-style personal portfolio for **Manazir**, a **first-year Zoology student at Aligarh Muslim University (AMU)**.

This is a work-in-progress customization. Personal photos, biography, projects, contact links, and other portfolio content can be added later. Do not treat the bundled demo applications and system resources as Manazir's personal work.

## Development

Requires Node.js 22+ and Yarn.

```bash
yarn install
yarn build:prebuild
yarn dev
```

Open http://localhost:3000. After editing files in `public/`, rerun `yarn build:prebuild` to regenerate filesystem indexes.
